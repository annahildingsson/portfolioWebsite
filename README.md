# 💻 Anna Hildingsson - Portfolio Website

A personal portfolio website showcasing my background, skills, projects and experience as a Computer Science student.

The website was created to present my work and technical skills in a simple, professional and user-friendly way.

## 🌐 Live Website

**Portfolio:** [https://annahildingsson.github.io/portfolioWebsite/](https://annahildingsson.github.io/portfolioWebsite/)

## ✨ About

This portfolio website was developed as a personal project to create an online space where I can showcase my education, technical skills, projects and previous experience.

The goal was to create a clean and responsive website that is easy to navigate and provides recruiters and potential employers with a quick overview of my background.

## 🛠️ Technologies

- HTML
- CSS
- JavaScript

## 📋 Features

- Responsive design
- Mobile-friendly layout
- About me section
- Education and experience
- Skills and technologies
- Project showcase
- Contact section
- Links to GitHub and LinkedIn
- Interactive navigation
- Responsive mobile menu

## 🎨 Design

The website was designed with a clean and modern aesthetic, focusing on readability, simplicity and usability.

The layout and visual design were created to keep the content easy to navigate while presenting projects and information in a professional way.

The website is fully responsive and adapts to different screen sizes, including desktop, tablet and mobile devices.

## 📂 Projects

The portfolio includes selected projects that demonstrate my experience with web development, programming and problem solving.

Each project provides an overview of the project, the technologies used and links to the relevant repository or live application where available.
